# 新增功能 — 播放列表管理器 + 文件管理器

**日期**: 2026-07-12
**Commit**: `12b09a4`

## 键 0 优先级

帮助面板现在始终渲染在最上层，无论在哪个视图下按 `0` 或 `Esc` 都能显示/关闭。

## 键 5：播放列表管理器

- 左侧：曲库歌曲列表
- 右侧：歌单面板
- 第一行 `...`：光标移到此处按回车新建歌单，自动进入输入模式
- 输入模式：键入歌单名称，回车确认，Esc 取消
- 歌单名：按回车展开/收起
- 展开后显示歌曲列表，光标移到歌曲上按回车删除
- 曲库歌曲上按回车：添加到当前展开的歌单
- 未展开歌单时添加：居中悬浮提示"请先展开一个歌单"

## 键 6：文件管理器

- 左侧：曲库（已有歌曲）
- 右侧：文件系统浏览器
- 进入时默认显示用户主目录
- 上方显示文件夹（📁），下方显示音频文件（🎵），不显示其他文件
- 文件夹按回车进入，Backspace 返回上级
- 音频文件按回车：添加到曲库（仅记录路径，不复制文件）
- 曲库歌曲按回车：删除曲库记录（不删除实际文件）
