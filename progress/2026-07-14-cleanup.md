# 2026-07-14 代码清理与优化

## 概述

系统性地处理项目中的代码质量问题：拆分大文件、清理 `#[allow(dead_code)]`、移除 `unsafe`、优化封面图数据结构。

## 变更清单

### 1. 拆分 `handlers/mod.rs` (896 → 645 行)

将播放控制相关方法提取到新文件 `src/app/playback.rs` (257 行)：

| 移动的方法 | 方法说明 |
|----------|---------|
| `move_selection` | 选择行移动（自动滚动） |
| `move_scroll` | 滚动偏移控制 |
| `play_selected` | 播放选中的曲目 |
| `next_track` | 下一首（支持歌单范围 + 全局回退） |
| `prev_track` | 上一首（支持歌单范围 + 全局回退） |
| `on_track_ended` | 曲目结束自动切换（三种 RepeatMode） |
| `start_fft` | 后台 FFT 分析线程（watch channel 取消） |
| `load_lyrics_for_current` | 当前曲目歌词加载 |
| `sync_lyrics` | 实时间步到当前歌词行 |

`handlers/mod.rs` 保留：事件分发 (`handle_event`)、键盘路由、命令模式、搜索、全局键绑定。

### 2. 清理 `#[allow(dead_code)]` 标注

| 文件 | 变更 | 原因 |
|------|------|------|
| `src/input/keymap.rs` | 保留文件级标注 | `stop` 键定义了但未接入 handler |
| `src/library/scanner.rs` | 改为方法级标注 | `pub fn` 但未在非测试代码中调用 |

| `src/playlist.rs` | 移除 impl 块标注 | 方法已接上 M3U 导入/导出 |
| `src/ui/mod.rs` | 保留 `TrackDisplay` 标注 | 字段用于未来扩展 |
| `src/app/handlers/settings.rs` | 移除多余 `return;` | clippy 发现 |

### 3. 移除 `unsafe` 代码

**文件**: `src/app/mod.rs:229`

`std::str::from_utf8_unchecked(chunk)` → `from_utf8(chunk).expect("base64 is always ASCII")`

理由：chunk 来自 base64 编码的输出，永远是有效 ASCII，但可用 `.expect()` 相同安全保证替代 `unsafe`。

### 4. 封面图数据结构优化

**文件**: `src/ui/mod.rs`, `src/app/persistence.rs`

`UiState.cover_art: Option<Vec<u8>>` → `Option<Arc<Vec<u8>>>`

赋值改为 `info.cover_art.map(Arc::new)`，读取时 Arc clone 仅增引用计数而非复制整个图片数据。
