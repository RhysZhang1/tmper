# 2026-07-17 代码结构优化

## 概述

根据全面代码审查反馈，执行三项结构性改进：提取硬编码常量、模块化封面渲染、统一视图切换逻辑。所有变更均为行为等价的重构，零功能变更。

## 变更清单

### 1. 提取运行时常量 (`src/constants.rs`)

将分散在多个文件中的 magic number 集中到 `src/constants.rs` 的 `runtime` 模块中：

| 常量 | 旧位置 | 含义 |
|------|--------|------|
| `PCM_BUFFER_CAPACITY` (8192) | `audio/engine.rs` ×3 | PCM 环形缓冲区容量 |
| `DEFAULT_SAMPLE_RATE` (44100) | `engine.rs`, `playback.rs` | 默认采样率 |
| `KEY_TIMEOUT_MS` (200) | `app/mod.rs`, `input/handler.rs` | 双键序列超时 |
| `VOLUME_STEP` (0.05) | `app/handlers/mod.rs` | 音量步进 |
| `NOTIFICATION_DURATION_SECS` (0.5) | `handlers/mod.rs`, `ui/mod.rs` | 通知自动消失 |
| `PLAYLIST_NOTIFICATION_SECS` (1.0) | `handlers/mod.rs` | 歌单通知消失 |
| `KITTY_CHUNK_SIZE` (4096) | `app/mod.rs` | Kitty 协议分块 |
| `FFT_SIZE` (2048) | `playback.rs` | FFT 窗大小 |
| `FFT_LOOP_SLEEP_MS` (32) | `playback.rs` | FFT 主循环间隔 |
| `FFT_WAIT_SLEEP_MS` (16) | `playback.rs` | FFT 数据不足等待 |

### 2. 提取封面渲染模块 (`src/ui/cover/mod.rs`)

将 `app/mod.rs` 中的封面渲染逻辑抽取为独立模块：

- **新 struct**: `CoverRenderer` 封装所有封面渲染状态：
  - Kitty 协议：`kitty_rendered`, `last_cover_gen`
  - SIXEL chafa：`chafa_available`, `last_cover_gen_chafa`, `chafa_sixel_cache`
  - 清理标志：`clear_pending`

- **公共接口**：
  - `CoverRenderer::new()` — 初始化 + chafa 检测
  - `render_kitty(&mut self, state: &UiState)` — Kitty 协议渲染
  - `render_chafa(&mut self, state: &UiState)` — SIXEL chafa 渲染
  - `needs_clear()` / `clear_done()` — SIXEL 残留清理标志

- **App 精简**: `app/mod.rs` 删除了 ~250 行方法体和函数（`render_cover_via_kitty`, `render_cover_via_chafa`, `which_chafa`, `is_kitty_graphics_compatible`），替换为 1 个 `cover_renderer: CoverRenderer` 字段 + 3 行调用

### 3. 统一视图切换 (`src/app/handlers/mod.rs`)

将分散的 toggle 模式替换为统一的 `switch_view()` 方法：

**之前**（每个视图独立的 toggle 逻辑，44 行）:
```rust
KeyCode::Char('3') => {
    self.ui_state.active_view = if self.ui_state.active_view == ViewMode::Lyrics {
        ViewMode::Player
    } else {
        ViewMode::Lyrics
    };
}
```

**之后**（所有视图统一调用，7 行）:
```rust
KeyCode::Char('3') => self.switch_view(ViewMode::Lyrics),
```

`switch_view()` 方法：
- 已在目标视图 → 切回 Player（toggle 行为不变）
- 目标不同 → 先执行视图特定初始化（`ensure_library_loaded` / `enter_playlist_view` / `enter_file_browser` / `rebuild_settings`），再切换

## 设计原则

所有变更遵循单一职责和低耦合原则：
- **constants.rs** — 全局调优参数单一来源
- **ui/cover/** — 封面渲染独立于 App 事件循环，仅依赖 `&UiState`（只读）
- **switch_view()** — DRY：视图切换逻辑一份代码，不再分散在 7 个 match 分支中
