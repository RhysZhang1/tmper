## Session 4.4 — 启动 FFT 线程 + 集成到 UI

### 新建/修改
| 文件 | 操作 | 说明 |
|------|------|------|
| `src/app.rs` | 修改 | FFT 线程 + 事件处理 + 视图切换 |
| `src/ui/mod.rs` | 修改 | 频谱面板 + 全屏视图 + pause decay |
| `src/event.rs` | 修改 | +VisualizerData 事件 |

### 关键实现
- `start_fft()` — `tokio::task::spawn_blocking` 启动 FFT 循环：
  1. 从 pcm_buffer 取 2048 个采样
  2. FFT → 分桶 → 平滑 → 归一化
  3. 写入 fft_data（Arc<Mutex>）
  4. sleep 32ms（≈30 FPS）
- Tick handler：读取 fft_data → 更新 UiState
- Pause decay：暂停时 bars *= 0.9 逐步衰减
- Player View：频谱 5 行（在进度条和歌词之间）
- 全屏频谱视图：键 `4` 切换
- 切歌自动重启 FFT 线程
