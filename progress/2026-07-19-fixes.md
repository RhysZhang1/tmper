# 2026-07-19 修复：回滚长按快进 + 性能/滚动修复

## 概述

回滚长按快进快退功能，并修复三个长期存在的 root-cause 问题：播放时滚动卡顿、迷你歌单末行消失、键1/键5播放列表状态耦合。

## 变更清单

### 1. 移除长按快进配置残留（回滚确认）

长按快进代码已在上一个会话中回滚。本次清理剩余配置项：

- `src/config.rs`: 移除 `PlaybackConfig::seek_step_large_secs` 字段及 `default_seek_step_large()` 函数
- `config/default.toml`: 移除 `seek_step_large_secs = 30`
- `README.md`: 同步移除配置示例中的对应行

`seek_step_small_secs` 保留，用于左/右方向键单步跳转。

### 2. 事件循环绘制节流（修复播放时滚动卡顿）

**根因**: 事件循环在每次 tick（30fps）和每次按键后都无条件调用 `terminal.draw()`。
播放时 30 ticks/秒 + 按键重复 ~30/秒 = 高达 60 draws/秒，与 FFT 线程竞争锁，导致 UI 响应延迟。

**修复** (`src/app/mod.rs`):
- 按键事件始终立即绘制（保持即时反馈）
- Tick 事件节流至最低 50ms 间隔（~20fps）
- 使用 `EventKind` 枚举跟踪事件来源
- 跳过不必要的绘制调用，释放 CPU 给音频管线

**效果**: 播放时按键处理不再与渲染竞争，滚动更流畅。

### 3. 键1 迷你歌单独立滚动状态（修复末行消失 + 状态耦合）

**根因**: 键1 播放器侧边栏和键5 歌单管理器共享 `selected_playlist` 和 `scroll_playlists` 字段，
但键1 渲染跳过了 "…" 行（索引 0），导致滚动坐标偏移错误。在模型坐标和侧边栏坐标之间
切换时出现最后一行不可见的 bug。

**修复**:
- `PlaylistManagerState` 新增 `sidebar_selected: usize` 和 `sidebar_scroll: usize` 字段
- `render_mini_playlist()` 使用独立侧边栏滚动状态，跳过 "…" 行
- `handle_player_view_sidebar_key()` 使用独立侧边栏光标，坐标范围不含 "…" 行
- 新增辅助方法: `sidebar_line_count()`, `sidebar_line_index_of_playlist()`, `clamp_sidebar_scroll()`
- 键5 歌单管理器继续使用 `selected_playlist` / `scroll_playlists`（含 "…" 行的完整模型）

**效果**: 
- 末行不再消失
- 键5 操作（如在 "…" 行创建歌单）不影响键1 侧边栏光标
- 两个视图对共享歌单数据执行各自独立的操作

## 已知遗留问题

- `seek_relative()` 仍使用同步解码——大文件跳转时会短暂卡顿。建议后续实现异步跳转路径（可复用 `play_file_async` 的 `Arc<Sink>` 模式）。
- `stdout` 直接写入封面（Kitty/SIXEL 协议）绕过 ratatui 差分缓冲——是伪按键事件的根因。`ratatui-image` 集成仍在规划中。
- 长按快进快退功能在当前 crossterm 架构下不可靠（无按键释放检测），等终端生态成熟后再考虑。

## 追加修复：末行消失（2026-07-19 第二轮）

经代码追踪确认三个根因：

1. **`visible_rows` 初始化为 20**：首次按键在首次 `render()` 之前处理，使用了过期的默认值 20 而非实际终端高度。
2. **`clamp_sidebar_scroll` 中 `vis` 差 1**：处理器使用 `visible_rows / 2`，但实际 widget 内部高度比此值**始终小 1**（边框偏移）——`scroll = selected - vis + 1` 公式会将光标置于可见区域外 1 行。
3. **键 5 UP 处理器不对称**：DOWN 调用 `clamp_playlist_scroll`，但 UP 使用缺少 `selected >= total` 边界检查的内联逻辑。结构变更后未调用 clamp。

### 追加变更

| 文件 | 变更 |
|------|------|
| `src/app/mod.rs` | 在事件循环前通过 `crossterm::terminal::size()` 获取实际终端高度初始化 `visible_rows` |
| `src/app/handlers/mod.rs` | `clamp_sidebar_scroll`: `vis = visible_rows/2 - 1`（修正 1 行偏移） |
| `src/app/handlers/playlist.rs` | UP 处理器现在调用 `clamp_playlist_scroll`（与 DOWN 对称）；歌曲删除后调用 clamp |
